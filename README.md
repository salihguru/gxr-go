Go runtime package for [GXR](https://github.com/salihguru/gxr) - A Go x React SSR framework with automatic partial hydration.

## Overview

`gxr-go` is the server-side rendering engine for GXR. It provides:

- 🚀 **Server-Side Rendering** - Render React/TSX components to HTML using Go
- ⚡ **Automatic Partial Hydration** - Components with `"use client"` directive are automatically prepared for client-side hydration
- 🎯 **Island Architecture** - Only interactive components are hydrated, keeping the bundle size minimal
- 🔧 **Zero Configuration** - Works out of the box with sensible defaults

## Installation

```bash
go get github.com/salihguru/gxr-go
```

## Quick Start

```go
package main

import (
    "fmt"
    "net/http"

    gxr "github.com/salihguru/gxr-go"
)

func main() {
    // Create GXR instance
    g, err := gxr.New()
    if err != nil {
        panic(err)
    }

    http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
        html, err := g.Render("pages/index.tsx", map[string]interface{}{
            "title": "Hello GXR!",
        })
        if err != nil {
            http.Error(w, err.Error(), 500)
            return
        }

        w.Header().Set("Content-Type", "text/html")
        w.Write([]byte(html))
    })

    http.ListenAndServe(":8080", nil)
}
```

## Configuration

```go
g, err := gxr.NewWithOptions(gxr.Options{
    SourceDir:  "./client",     // Directory containing TSX files (default: ".")
    PublicPath: "/public",      // URL path for static assets (default: "/public")
})
```

## How It Works

### Server Components (Default)

Regular components are rendered to static HTML on the server:

```tsx
// components/Header.tsx
export default function Header({ title }: { title: string }) {
  return <header><h1>{title}</h1></header>
}
```

### Client Components

Components with `"use client"` directive are rendered on the server and hydrated on the client:

```tsx
// components/Counter.tsx
"use client"

import { useState } from "react"

export default function Counter({ initialCount }: { initialCount: number }) {
  const [count, setCount] = useState(initialCount)
  return (
    <button onClick={() => setCount(c => c + 1)}>
      Count: {count}
    </button>
  )
}
```

GXR automatically:
1. Renders the component to HTML on the server
2. Injects hydration markers (`data-hid`)
3. Collects props for client-side hydration
4. Injects the hydration script before `</body>`

### Project Structure

```
my-app/
├── client/
│   ├── components/
│   │   ├── Counter.tsx    # "use client" component
│   │   └── Header.tsx     # Server component
│   └── pages/
│       └── index.tsx      # Page template
├── public/
│   └── hydrate.js         # Generated by `npx gxr build`
├── main.go
└── go.mod
```

### Build Client Bundle

Use the GXR CLI to build the hydration bundle:

```bash
npx gxr build --components ./client/components --output ./public
```

## API Reference

### `gxr.New() (*GXR, error)`

Creates a new GXR instance with default options.

### `gxr.NewWithOptions(opts Options) (*GXR, error)`

Creates a new GXR instance with custom options.

### `(*GXR).Render(page string, props map[string]interface{}) (string, error)`

Renders a TSX page with the given props and returns HTML string.
